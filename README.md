# Car-bike-rental-app
A full-featured Car and Bike rental web application built using React JS. This project allows users to browse, search, and rent cars or bikes with ease. It includes real-time booking, filtering options, user authentication (Firebase), payment integration, and responsive UI with Bootstrap.
## ✨ Features

- 📱 **Responsive Design**: Built with React Bootstrap and SASS to ensure compatibility across all screen sizes.
- 🧭 **Client and Server-Side Routing**: Implemented using React Router DOM v6.
- 🔄 **Global State Management**: Managed using React Redux and persisted with Redux Persist.
- 🔐 **User Authentication & Data Handling**: Integrated with Google Firebase for authentication, Firestore database, and file storage.
- 💬 **Interactive UI**: Enhanced with SweetAlert2 for elegant custom pop-ups and alerts.

# 🧩 Modules & Libraries Used

- **React Bootstrap** & **SASS** – for responsive and scalable UI.
- **React Router DOM v6** – for navigation and routing.
- **React Redux** – for global state management.
- **Redux Persist** – to persist state across sessions.
- **Google Firebase** – for:
  - Authentication
  - Firestore Database
  - Firebase Storage
- **SweetAlert2** – for modern popup alerts and confirmations.
